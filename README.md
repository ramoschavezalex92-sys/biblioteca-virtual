# Biblioteca Virtual - Publicación Web

Este proyecto es una biblioteca digital estática en HTML/CSS/JS.

## Ya está listo para publicar

- El archivo principal ahora es `index.html`.
- La página que estabas editando en `index1.html` ya se copió a `index.html`.
- Si quieres un enlace público, lo mejor es usar GitHub Pages o Netlify.

## Opción 1: GitHub Pages

1. Crea una cuenta en GitHub si no la tienes.
2. Crea un nuevo repositorio público.
3. Sube todos los archivos del proyecto.
4. En el repositorio, ve a `Settings` > `Pages`.
5. Configura `Source` en la rama `main` (o `master`) y la carpeta `/(root)`.
6. Guarda. En unos minutos tendrás un enlace tipo `https://TU_USUARIO.github.io/NOMBRE_REPO`.

> Si usas GitHub Desktop o Git en tu PC, basta con hacer `git init`, `git add .`, `git commit -m "Initial commit"`, y luego `git remote add origin ...` y `git push -u origin main`.

## Opción 2: Netlify Drop

1. Abre https://app.netlify.com/drop
2. Arrastra la carpeta del proyecto (`biblioteca-virtual`) al área de la página.
3. Netlify publicará el sitio automáticamente y te dará un enlace público.

## Opción 3: Google Drive no es suficiente

- Google Drive puede alojar archivos, pero no es una forma fácil de publicar un sitio web completo con un enlace bonito.
- La mejor opción para este caso es GitHub Pages o Netlify.

## No pude inicializar Git aquí

El entorno actual no tiene `git` instalado, así que no pude crear el repositorio desde aquí.

## Siguiente paso recomendado

Si quieres, te guío paso a paso para:

- instalar Git en Windows,
- crear un repositorio en GitHub,
- subir este proyecto,
- activar GitHub Pages y obtener la URL pública.
